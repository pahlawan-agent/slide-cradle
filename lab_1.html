PHP Comments

01

Comments in PHP

Comments help document your code and are ignored by PHP:

  • Single-line comments:
    • Use // for single-line comments (most common)
    • Use # as an alternative (less common)
    • Everything after the comment marker is ignored
  • Multi-line comments:
    • Use /* */ to comment multiple lines
    • Can span across multiple lines
    • Useful for longer explanations or temporarily disabling code
  • Best practices:
    • Write clear, descriptive comments
    • Explain why, not what (code should be self-explanatory)
    • Keep comments up-to-date with code changes
💬
<?php
// This is a single-line comment using //
$name = "John"; // Comment after code
# This is also a single-line comment using #
$age = 25;
/*
* This is a multi-line comment
* It can span multiple lines
* Useful for longer explanations
*/
echo "Hello, " . $name;
?>

Variables in PHP

02

Variables

Variables in PHP:

  • Start with a dollar sign ($)
  • Case-sensitive ($name ≠ $NAME)
  • No need to declare data type (loosely typed)
  • Automatically converted between types as needed
  • No explicit declaration needed before use
  • Value can change during script execution
🔄
<?php
// Variable declaration and assignment
$name = "John";
$age = 25;
$height = 1.85;
$isStudent = true;
// Using variables
echo "Name: " . $name . "<br>";
echo "Age: " . $age . "<br>";
// Changing variable values
$age = 26;
echo "New age: " . $age . "<br>";
// Variable of different type
$age = "twenty-six"; // Now a string
?>

  • Scalar Types:

String Operations

03

String Concatenation

String concatenation combines multiple strings into one:

  • Concatenation operator:
    • Use the dot (.) operator to join strings
    • Can concatenate strings, variables, and expressions
  • String interpolation:
    • Use double quotes for variable interpolation
    • Variables are automatically converted to strings
  • Best practices:
    • Use concatenation for complex expressions
    • Use interpolation for simple variable insertion
🔗
<?php
// Basic concatenation with dot operator
$firstName = "John";
$lastName = "Doe";
$fullName = $firstName . " " . $lastName;
echo $fullName; // John Doe
// String interpolation with double quotes
$age = 25;
echo "Hello, my name is $fullName and I am $age years old.";
// Hello, my name is John Doe and I am 25 years old.
// Complex concatenation
$greeting = "Welcome, " . $firstName . "! You are " . $age . " years old.";
echo $greeting;
?>

Naming Convention

03

PHP Naming Conventions

Rules for naming variables, functions, and classes:

  • Variables:
    • Must start with $ followed by a letter or underscore
    • Can contain letters, numbers, and underscores
    • Cannot contain spaces or special characters
    • Typically use camelCase: $firstName
  • Functions:
    • Should be descriptive and use camelCase
    • Example: calculateTotal(), getUserData()
  • Classes:
    • Use PascalCase (first letter capitalized)
    • Example: UserProfile, DatabaseConnection
📝
<?php
// Variable naming examples
$firstName = "John"; // camelCase (recommended)
$last_name = "Doe"; // snake_case
$_userId = 42; // valid (starts with underscore)
// Invalid variable names
// $1name = "Invalid"; // Cannot start with a number
// $user-name = "Invalid"; // Cannot contain hyphens
// Function naming
function calculateTotal($price, $quantity) {
return $price * $quantity;
}
// Class naming
class UserProfile {
// Class properties and methods
}
?>

Arrays

04

Indexed Arrays

Indexed arrays use numeric keys (starting from 0):

  • Accessing elements:
    • Use square brackets with index: $array[index]
    • Indices start at 0
    • Returns the value at that position

Interactive Array Access

$colors = ["Red", "Green", "Blue", "Yellow", "Purple"];
$colors [ ]
// Type an index and press Enter
<?php
// Creating an indexed array
$colors = [
"Red", // index 0
"Green", // index 1
"Blue", // index 2
"Yellow", // index 3
"Purple" // index 4
];
// Accessing array elements by index
$firstColor = $colors[0]; // "Red"
$thirdColor = $colors[2]; // "Blue"
// Using a variable as the index
$index = 3;
$selectedColor = $colors[$index]; // "Yellow"
?>

Arrays

04a

Alternative Array Declaration

You can also declare indexed arrays using the array() function:

  • Using array() function:
    • Alternative syntax to square brackets []
    • Equivalent functionality - both create indexed arrays
    • Older style, but still widely used
    • Values are passed as function arguments
<?php
// Using array() function (alternative syntax)
$colors = array(
"Red", // index 0
"Green", // index 1
"Blue", // index 2
"Yellow", // index 3
"Purple" // index 4
);
// Both syntaxes are equivalent
$colors1 = ["Red", "Green", "Blue"];
$colors2 = array("Red", "Green", "Blue");
// $colors1 and $colors2 are identical
// Accessing works the same way
$firstColor = $colors[0]; // "Red"
?>

Arrays

05

Associative Arrays

Associative arrays use named keys instead of numeric indices:

  • Accessing elements:
    • Use square brackets with key: $array['key']
    • Keys are case-sensitive
    • Returns the value associated with that key

Interactive Associative Array Access

$user = [
"name" => "John Doe",
"email" => "john@example.com",
"age" => 28,
"active" => true,
];
$user [ ]
// Type a key and press Enter
<?php
// Creating an associative array
$user = [
"name" => "John Doe",
"email" => "john@example.com",
"age" => 28,
"active" => true,
];
// Accessing array elements by key
$name = $user["name"]; // "John Doe"
$isActive = $user["active"]; // true
// Using a variable as the key
$key = "email";
$userEmail = $user[$key]; // "john@example.com"
?>

If-Else Statements

06

Conditional Statements

Conditional statements execute code based on conditions:

  • Basic if statement:
    • Executes code if condition is true
  • if-else statement:
    • Provides alternative code for false condition
  • if-elseif-else statement:
    • Tests multiple conditions in sequence
  • Nested if statements:
    • Conditions inside other conditions
🔀
<?php
// Basic if statement
$age = 18;
if ($age >= 18) {
echo "You are an adult.";
}
// if-else statement
$score = 75;
if ($score >= 60) {
echo "You passed!";
} else {
echo "You failed.";
}
// if-elseif-else statement
$grade = 85;
if ($grade >= 90) {
echo "A";
} elseif ($grade >= 80) {
echo "B";
} elseif ($grade >= 70) {
echo "C";
} else {
echo "F";
}
?>

If-Else Statements

07

Switch Statement

The switch statement is an alternative to multiple if-elseif statements:

  • Basic structure:
    • switch expression to evaluate
    • case statements for different values
    • default case for no matches
  • Important notes:
    • Uses loose comparison (==) by default
    • break statement prevents fall-through
    • Multiple cases can share the same code block
    • default is optional but recommended
  • Best used when:
    • Comparing a variable against many values
    • Code readability is important
🔄
<?php
// Basic switch statement
$day = "Wednesday";
switch ($day) {
case "Monday":
echo "Start of work week";
break;
case "Wednesday":
echo "Middle of work week";
break;
case "Friday":
echo "End of work week";
break;
case "Saturday":
case "Sunday":
echo "Weekend!";
break;
default:
echo "Regular work day";
}
// Outputs: Middle of work week
?>

Loops

08

For Loop

The for loop executes code a specified number of times:

  • Basic structure:
    • Initialization: executed once before the loop starts
    • Condition: evaluated before each iteration
    • Increment/decrement: executed after each iteration
    • Code block: executed if condition is true
  • Common uses:
    • Iterating a specific number of times
    • Processing arrays with numeric indices
    • Generating sequences
  • Control flow:
    • break: exits the loop completely
    • continue: skips the current iteration
🔄
<?php
// Basic for loop
for ($i = 1; $i <= 5; $i++) {
echo $i . " ";
}
// Outputs: 1 2 3 4 5
?>

Loops

09

Foreach: Indexed Arrays

Iterate over sequential lists (indexed arrays):

  • Basic structure:
    • foreach (array as value) - gets only values
  • Advantages:
    • No need to know array size or keys in advance
    • More readable for array iteration
🔄
<?php
// Basic foreach with values only
$fruits = ["Apple", "Banana", "Cherry"];
foreach ($fruits as $fruit) {
echo $fruit . "<br>";
}
?>
💡 Click on $fruits to highlight, or edit the variable name directly in the code!

Loops

09

Foreach: Associative Arrays

Iterate over key/value maps (associative arrays):

  • Keys and values: foreach ($arr as $key => $value)
  • Tip: Order follows insertion, not alphabetical
  • Note: Variable names are customizable
🗂️
<?php
$user = [
"name" => "John",
"email" => "john@example.com",
"age" => 28
];
foreach ($user as $key => $value) {
echo $key . ": " . $value . "<br>";
}
?>
💡 Try editing the variable names directly in the code!

Functions

10

Function Most Basic Structure

Functions are blocks of reusable code:

  • Basic structure:
    • function keyword
    • Function name (should be descriptive)
    • Parameters (optional)
    • Return value (optional)
  • Benefits:
    • Code reusability
    • Better organization
    • Easier maintenance
    • Improved readability
  • Function scope:
    • Variables inside functions are local by default
    • Use global keyword to access global variables
📦
<?php
// Basic function definition
function sayHello() {
echo "Hello, World!";
}
// Calling the function
sayHello(); // Outputs: Hello, World!
?>

Functions

11

Function With Parameter

PHP offers flexible parameter handling in functions:

  • Default parameter values:
    • Assign default values to parameters
    • Makes parameters optional
<?php
// Function with parameters
function greet($name) {
echo "Hello, " . $name . "!";
}
greet("John"); // Hello, John!
?>
<?php
// Function with default parameters
function setHeight($height = 50) {
echo "Height is: " . $height . "<br>";
}
setHeight(80); // Height is: 80
setHeight(); // Height is: 50 (default)
?>

Functions

12

Multiple Parameters

Functions can accept multiple and variable numbers of parameters:

  • Multiple fixed parameters:
    • Define each parameter in order
    • Callers must pass arguments in the same order
  • Defaults with many params:
    • Later parameters can provide default values
    • Defaults make arguments optional
<?php
// Multiple fixed parameters
function greet($salutation, $name) {
return $salutation . ", " . $name . "!";
}
echo greet("Hello", "John"); // Hello, John!
?>

Functions

13

Return Values

Functions can compute and return results to the caller:

  • Using return:
    • return sends a value back to the caller
    • Execution stops at the first return
  • Return types:
    • Return strings, numbers, arrays, objects, or null
    • Return early to handle invalid input
<?php
// Simple return value
function fullName($first, $last) {
return $first . " " . $last;
}
$name = fullName("Ada", "Lovelace");
echo "Name: " . $name; // Name: Ada Lovelace
?>
